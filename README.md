# HTTP POST ツール

外部ライブラリやビルドツール不要で動く、HTML / CSS / JavaScript 製のシンプルな HTTP POST ツールです。

## ファイル構成

- `index.html` - 画面本体（CSS・JavaScript をインラインで内蔵した 1 ファイル完結構成）
- `sample-config.json` - 読み込み用サンプル設定ファイル

## 使い方

画面右上の切り替えボタンで **実行モード**（初期表示）と **設定モード** を切り替えられます。

### 実行モード（シンプル実行用）
1. 送信先 URL（読み取り専用）を確認します。
2. 定義された変数のテキストボックス／プルダウンに値をセットします。
   - 必要に応じて **JSONファイル読込** から別の設定を読み込めます。
3. **実行（POST送信）** を押すと右側のレスポンス欄に結果が表示されます。

### 設定モード（URL・ヘッダー・ペイロード・変数の編集用）
1. `index.html` をブラウザで開きます。
2. **エンドポイント** に送信先 URL を入力します（メソッドは `POST` 固定）。
3. **変数** セクションで「＋変数追加」を押し、変数名・種類（`テキスト` / `選択肢`）・値を設定します。
   - 種類を `選択肢` にすると、カンマ区切り（例: `dev, stg, prod`）で選択肢を編集でき、プルダウンから値を選べます。
   - 変数名が空または重複している行は赤く強調表示されます。
4. **ヘッダー**・**ペイロード** を入力します。URL・ヘッダー値・ペイロード内で `{{変数名}}` を使うと、展開結果が **送信プレビュー** にリアルタイム表示されます。
   - **JSON 送信時の注意**: 変数の値はエスケープせずそのまま埋め込まれます。文字列として送る場合は `{"name": "{{name}}"}` のようにテンプレート側で引用符 `"` を書いてください。
5. **送信** ボタンを押すと右側のレスポンス欄にステータスコード、所要時間（ms）、レスポンスヘッダー、整形されたレスポンスボディが表示されます。

## 設定の保存・読み込み

- **ローカルストレージに保存 / 読込**: ブラウザの `localStorage`（キー: `httpPostTool.config`）に設定を保存・復元します。保存済みの設定がある場合はページを開いた際に自動読み込みされます。
- **JSONファイル読込 / JSONエクスポート**: 設定を `post-config.json` として書き出したり、`sample-config.json` などの JSON ファイルを読み込んだりできます。

## `file://` で開いた場合の CORS 制約について

`index.html` をローカルファイル（`file://...`）としてブラウザで直接開いた場合、ブラウザのセキュリティ仕様（Origin が `null` 扱い）により、送信先サーバーが適切な CORS ヘッダー（`Access-Control-Allow-Origin`）を返さないとリクエストがブロックされ、「ネットワークエラー / CORSの可能性」と表示されることがあります。

必要に応じて、ローカル HTTP サーバー経由で開くか、CORS を許可したテスト用エンドポイント（例: `https://httpbin.org/post`）をご利用ください。

```bash
python3 -m http.server 8000
```
